# 多点壁纸 - 鸿蒙多形态设备壁纸平台

> 鸿蒙 HarmonyOS 5.0+ 壁纸展示、预览、下载、收藏工具 APP

## 📌 项目速览

| 项目信息 | 说明 |
|---------|------|
| **项目名称** | 多点壁纸 |
| **适配系统** | HarmonyOS 5.0+ |
| **设备适配** | 手机竖屏、平板横屏、两折折叠屏、三折折叠屏 |

## 🔧 核心功能清单

### 1. 设备形态分类系统（核心特色）

首页顶部四大分类标签，一键切换：

| 分类 | 适配设备 | 资源池 |
|-----|---------|--------|
| 竖屏壁纸 | 常规鸿蒙手机 | 独立 |
| 横屏壁纸 | 平板、智慧屏 | 独立 |
| 两折叠壁纸 | 竖向/横向两折屏 | 独立 |
| 三折叠壁纸 | 三折大屏专属 | 独立 |

> ⚠️ 四个分类资源池互不混杂，后台上传时必须指定设备形态标签

### 2. 用户权限体系

```
未登录状态:
  ✅ 浏览壁纸
  ❌ 收藏 → 弹窗提示"请登录后使用"
  ❌ 下载 → 弹窗提示"请登录后使用"
  ❌ 上传 → 弹窗提示"请登录后使用"

已登录状态:
  ✅ 浏览壁纸
  ✅ 收藏/取消收藏
  ✅ 下载壁纸
  ✅ 上传壁纸（审核后上架）
  ✅ 个人中心管理
```

### 3. 核心功能模块

| 模块 | 功能点 |
|-----|--------|
| **登录** | 账号密码登录、华为账号登录（预留）、登录状态持久化 |
| **收藏** | 加入收藏、取消收藏、云端同步、批量删除 |
| **下载** | 高清下载、自动保存相册、设为壁纸 |
| **上传** | 用户投稿 → Webhook通知管理员 → 审核 → 上架/驳回 |
| **搜索** | 关键词搜索、热词推荐、搜索历史 |
| **分类** | 题材二级分类（简约、风景、动漫、科技、国风等） |
| **标签** | 关键字、标签、说明（用户上传时必填，管理员可补充） |
| **推荐** | 最新上架、热门下载、精选置顶 |
| **后台** | 壁纸审核、上传管理、分类管理、数据统计、下架删除 |

### 4. 壁纸元数据结构

```typescript
interface Wallpaper {
  id: string;
  deviceType: 'portrait' | 'landscape' | 'fold2' | 'fold3';
  genre: string[];           // 题材标签：简约、风景、动漫、科技...
  keywords: string[];        // 关键字：夕阳、海边、少女...
  description: string;       // 壁纸说明/简介
  author: string;            // 上传者
  status: 'pending' | 'approved' | 'rejected';
  coverUrl: string;
  originalUrl: string;
  downloadCount: number;
  favoriteCount: number;
  createdAt: string;
}
```

### 5. 用户上传功能（预留）

```
用户上传流程:
1. 用户选择图片 → 填写设备形态/题材/关键字/说明
2. 前端提交 → 后端存储 → Webhook通知管理员
3. 管理员后台审核 → 通过（公开）/ 驳回（附原因）
4. 审核通过后 → 进入公共资源池 + 展示在用户"我上传的"

Webhook通知内容:
- 壁纸ID、缩略图、用户信息、提交时间
- 管理员点击跳转审核页
```

### 6. 第三方登录（预留）

| 登录方式 | 状态 | 说明 |
|---------|------|------|
| 账号密码 | 必做 | 基础登录方式 |
| 华为账号 | 预留 | 鸿蒙生态一键登录（后期接入） |

### 7. 鸿蒙原生特性适配

- ✅ 折叠屏动态适配（展开/折叠状态自动切换布局）
- ✅ 深色/浅色模式跟随系统
- ✅ 元服务壁纸卡片
- ✅ 轻量化安装、无后台驻留

## 📋 开发强制规则

### 硬性约束（违反即报错）

1. **协议强制**：首次启动必须弹窗用户协议+隐私政策，拒绝则退出 APP
2. **版本门槛**：HarmonyOS 5.0 以下提示版本过低，禁止进入
3. **权限精简**：仅申请相册存储、网络权限，禁止定位/麦克风/通讯录
